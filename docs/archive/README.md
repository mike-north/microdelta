# Historical material

Start with [the active specification](../spec/README.md).

Everything in `pre-consolidation/` is historical context from before the
2026-09-26 consolidation. It contains superseded requirements, rejected proposals,
and experimental API sketches. It must not govern implementation or compete with
the active specification. The [reconciliation](../spec/reconciliation.md) explains
what changed and where the preserved requirements now live.

The archive preserves the old decision chronology and source attachments without
requiring agents to reconstruct authority from dates. It also contains executable
exploration fixtures whose original API proposals are not the selected runtime.
Those fixtures are evidence of limited earlier probes, not new acceptance tests.
