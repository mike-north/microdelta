## Scope of the observed behavior

The [EXP-1 fixture](../../experiments/exp-1/README.md) starts independent Node
processes with fresh allocations and reordered member invocation. It retains
exact result references with zero consumer executions when observed evidence
matches, and invalidates only the affected retained work when consumed facts
change. Compatibility rollback does not rewind current pointers. Its preserved
untracked-capture counterexample prevents a claim of arbitrary closure soundness.
Promise/thenable and accessor regressions enforce the bounded synchronous surface.

The [EXP-2 matrix](../../experiments/exp-2/README.md) states supported and rejected
values, literal observation distinctions, format versions, and selected-loading
assumptions. Fingerprint-only verification reads no payload, with a positive
control proving the reader is observable. Explicit key enumeration survives
snapshot transport separately from unordered equality. Scalar views reject
unimplemented nested and metadata operations rather than report false facts.
The result does not establish cache budgets, eviction, or large-data performance.

The [EXP-3 protocol](../../experiments/exp-3/protocol.md) records actual child-process
termination at authoritative boundaries. It distinguishes staged data, committed
success, lost acknowledgment, and observer failure. Exact history survives later
publication. The evidence covers process termination and reopen under the tested
SQLite configuration; it does not prove power-loss, device/filesystem failure,
network filesystem, distributed clock, multi-host, or general concurrency safety.

The combined local `npm run check`, `npm test`, and `npm run build` passed before
PR #19 acceptance. The tests included 78 tooling cases, 24 EXP-1 cases, 28 EXP-2
cases, five SQLite capability cases, twelve publication cases, package suites,
and tsd. Hosted matrices subsequently checked the accepted commit on all three
Node versions. Per-experiment records preserve initial failing assertions and
later regression evidence; aggregate passing counts do not replace those records.
