  equal consumed values and compares later changes at the new path` and `compares
  selected facts through current bindings while preserving original evidence`
  prove current selected-fact comparison. They do not prove durable assessment reuse.
- **A-15:** generated alpha tsd consumers, strict public consumers with
  `skipLibCheck: false`, declaration-tier exclusion, canonical brand identity,
  source/import boundaries, and API report gates constrain the new surfaces.
  Declaration cleanup tests regenerate genuine raw API Extractor output to prove
  the orphan alpha import failure before testing the supported postpass. They
  retain used imports and reject unsupported declaration import forms.
- **A-17, bounded M2 slice:** [Materialization tests](../../packages/materialization/test/materialization.test.ts)
  exercise two scalar consumers, unread large sibling counters, exact saved
  references, copied locators, and current-reference metadata comparisons for
  equal, changed, and unavailable results without payload fallback. Metadata is
  preindexed separately from payload; explicit reading is the positive control.
  Separate reader capabilities govern projection loading. These are fake-reader
  port/consumer assertions, not physical backend I/O or scale proof.
- **A-18:** observer tests cover async frame isolation, post-await tracked calls,
  restored nested capture, late-use rejection, and cached successful/failed
  derivation replay. New materialized-output, projection, and member-order variants
  have direct replay coverage. Materialization entrypoints reject inherited closed
  frames before any reading, copying, or hashing, including local-only output.
- **Collection semantics:** [Value projection tests](../../packages/value/test/projection.test.ts)
  and Materialization tests distinguish unordered selected content from explicitly
  consumed member order, preserve actual visited sequence, reject duplicate keys
  and false exhaustive coverage, and detect insertion/deletion/selected changes.
  Returned content is Value's canonical normal form, so equal fingerprints cannot
  conceal differing member or nested-record order in returned projection data.
