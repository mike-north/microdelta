## Public compatibility and release truth

The public declaration rollup still exports only the History Store API,
including `createMemoryStore`; the
[API report](../../packages/core/etc/microdelta.api.md) adds only `@alpha` items.
The [facade tsd consumer](../../packages/core/test-d/facade.test-d.ts) checks
that the public entry rejects workspace exports.

The M3 workspace surfaces are in the `@alpha` declaration tier. That tier is
project-private and separate from package publishability. The only packages
published were user-authorized `0.0.0` (and earlier `0.0.0-bootstrap.0`)
namespace-bootstrap placeholders without runtime code ([releasing](../releasing.md)). No M3 implementation release exists,
and Version [PR49](https://github.com/mike-north/microdelta/pull/49) was not
merged.

## Scope and limits

- **Single logical writer.** One SQLite file, one host and sequential processes.
  No concurrent workers and no M5 retry, cancellation or accounting.
- **Direct-child validation only.** General nested arguments, fanout, folds,
  parent cutoff and TEST-3/4 remain M4.
- **Process kill is not power loss.** Distributed durability and time are not
  claimed.
- **Kill points.** They are chosen by commit role and occurrence within one
  deterministic invocation. Exactly-once external work before a commit is not
  claimed.
- **Node versions.** Local runs used Node 24; CI covers Node 20/22/24.
- **Not in M3.** The CLI (M6), scale and eviction (M7), paid provider calls and
  live GitHub.
