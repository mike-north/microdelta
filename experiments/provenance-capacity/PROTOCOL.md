# Bounded provenance-capacity investigation

This EXP-0 investigation sizes the exact cold listing provenance. It does not execute the qualification harness or alter runtime semantics. The required external local manifest pins three private accepted database copies and accepted reports; private paths, raw databases and their digests stay outside this repository.

Before opening each database, hash its file and require the manifest digest. Verify the accepted lineage receipt digest, locate its unique accepted cold phase and verify that domain receipt digest and identities. Obtain the listing locator from that cold graph summary; do not guess a result ordinal or use a later current pointer. Open only `mode=ro&immutable=1`. Select one exact result/scope row per database, at most three rows total. Query only scalar identity/format/version/prefix, observation-array length and canonical character/byte lengths. Assert the plain MDS1 observation path, source identity and ASCII surface. Only the N=12 canonical cell may be returned, using an SQL CASE byte cap of 1 MiB; larger cells remain within SQLite. Close and rehash every database.

Diagnostic workers are limited to 120 seconds, 2 GiB RSS and 1 GiB new artifacts. A private parent watchdog enforces the deadline and stops on missing RSS samples or sampled RSS above the ceiling; process high-water RSS is checked separately. Sampled RSS is not a guarantee of transient peak observation. macOS rejected an attempted address-space limit before any database open; no address-space cap is claimed. Stop on any identity, shape, bound or measured/predicted mismatch. Do not retry qualification or inspect its failed database. Compiler/repository gates are separate from these diagnostic bounds.

The independent counter accepts only plain or null-prototype records, ordinary dense arrays, strings and finite safe integers; all other Value features reject. It counts the MDS1 prefix and exact JSON/wire scaffolding without building wire text. UTF-16 units and UTF-8 bytes remain distinct. Tiny mathematical shape controls use the actual generated sibling Value codec; they are not source callback captures or new qualification stages. Parametric arithmetic never builds the full-size observation population.

Tests first establish exact tiny totals, escaping, Unicode and decimal-width boundaries, omission/address sensitivity, invalid-domain rejection, safe arithmetic and exact scalar row/cell guards. Actual tiny retained content must match every ordered observation, binding, address, selection, operation, encoded fact and digest. Negative deletion and altered repeated-address controls must reject. Existing History rejection/SQL rollback tests are credited; a separate minimal provenance-content rejection case covers the remaining preservation gap.

Acceptance needs actual RED/GREEN receipts, pinned local generated/source identity, the three scalar measurements, independent source-shape reconciliation, safe arithmetic and explicit conditional capacity conclusions. Any repair, transport decision or qualification retry is a separate root decision.
