# Selected-subtree query work gate

This gate covers History's `subtree-payload` read used during keyed roster discovery. Run `npm run test:subtree-query` after package build, or use `npm test`. The runner creates fresh stores, executes the actual facade through the Node Machine SQLite adapter at 10, 20 and 40 members, records the SQL and bound values that ran, and captures the relevant live schema and listing rows. It writes full evidence to a temporary directory reported at the end.

The Node check explains that exact executed query with its bound values against the same store. Every recursive edge access must use the `(result_id, parent_node)` primary-key prefix, and both prototype and final node accesses must use `(result_id, node_id)`. It applies the same qualification to the frozen old query as a negative. A CTE frontier scan is expected; a result-wide edge scan is not. The facade assertions check successful statuses, real member keys and score payloads, source/member body counts, exact subjects, one subtree node/edge read per discovery, and normal close.

The Python check executes the captured SQL and schema over the captured listing rows, counting SQLite VM instructions. A regression check remaps those rows and actual query bindings to a non-1 result ID; the linear and broad-scan controls must still use that listing and retain their positive/negative outcomes. The predeclared finite bound is `W(2N) <= 2*W(N)+500` for both doublings. The selected node and edge queries must pass; a frozen old query and a deliberate broad scan must fail. Captured rows also have checked expected counts. This finite comparison is not a wall-clock SLA, an actual Node VM count, or a universal complexity proof. The Node access-path assertion supplies the separate actual-engine qualification. The local tested versions were Node SQLite 3.53.0 and Python SQLite 3.54.0; other engine/platform behavior must be read from that run's fresh evidence rather than inferred from these versions.

History's durable reader suite separately checks nested result/sibling row isolation, root coverage, accepted Value shapes including sparse arrays and prototypes, exact references, digest reconstruction, corruption failures, and fingerprint reads without payload loading. The gate does not change the Value domain or prove 100,000-member capacity.
